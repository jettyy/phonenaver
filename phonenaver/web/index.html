1. 네이버 로그인

로그인 세션은 이 컴퓨터에만 저장됩니다.

[네이버 로그인 창 열기] 를 누르면 진짜 브라우저 창이 뜹니다. 아이디·비밀번호는 그 창에 직접 입력하세요 (2단계 인증도 그대로). '로그인 상태 유지'를 체크하면 더 오래 유지됩니다.
한 번만 로그인하면 계속 유지됩니다. 프로그램이 켜져 있는 동안 브라우저를 계속 열어 두고, 로그인 쿠키를 따로 보관했다가 되살리기 때문에 껐다 켜도 다시 로그인할 필요가 없습니다. 프로그램이 아이디·비밀번호를 대신 입력하지 않아서 반복 로그인으로 차단될 일도 없습니다.

2. 글쓰기 요청

휴대폰으로 보내는 것과 똑같이 쓰면 됩니다

⭐ 버튼으로 저장하면 위에 버튼이 생겨서, 자주 쓰는 요청을 누르기만 하면 다시 채워집니다 (계속 남아 있습니다).
· 키워드/문장 → 최신 정보 검색 후 작성 · 링크 → 들어가서 분석 · 유튜브 링크 → 영상 대사(자막) 분석 · 유튜브 채널 링크 → 최근 6개월 영상마다 글 하나씩 · "이 링크 넣어줘" → 본문에 링크 삽입
· 그대로: 로 시작하면 쓴 글 그대로 저장 · 카테고리: 이름 으로 직접 지정 (안 쓰면 알아서 고름) · 사진 없이 → 이미지 생략
· 넣은 순서대로 하나씩 처리합니다. 휴대폰으로 보낸 요청도 같은 목록(아래 5번)에 줄을 섭니다.

3. 휴대폰 (텔레그램) 연결

-

① 휴대폰 텔레그램에서 @BotFather → /newbot → 이름 정하기 → 받은 토큰을 위 칸에 넣고 [토큰 저장]
② [휴대폰 연결] 을 누른 뒤 휴대폰에서 내 봇에게(여러 컴퓨터용이면 그룹에) 아무 메시지나 보내면 자동으로 등록됩니다
등록이 끝나면 프로그램을 켤 때마다 봇도 자동으로 켜집니다. 등록된 휴대폰(또는 그룹)의 메시지만 처리합니다.

여러 컴퓨터(블로그)에 한 번에 시키기 — 한 번 보내면 컴퓨터마다 각자 글을 써서 각자 블로그에 저장

텔레그램 봇 하나는 한 컴퓨터에서만 켤 수 있습니다 (같은 봇을 두 곳에서 켜면 "Conflict" 오류). 대신 컴퓨터마다 봇을 하나씩 만들고, 그 봇들을 한 그룹에 넣으면 그룹에 한 번 보낸 메시지를 모든 컴퓨터가 동시에 받습니다.

  1. @BotFather 에서 컴퓨터 수만큼 봇을 만듭니다 (예: 블로그A봇, 블로그B봇, 블로그C봇)
  2. 각 봇마다 @BotFather → /setprivacy → 봇 선택 → Disable (그룹의 모든 메시지를 받게 함)
  3. 텔레그램에서 새 그룹을 만들고 봇 3개를 모두 초대합니다 (이미 넣었다면 빼고 다시 초대. 또는 봇들을 그룹 관리자로 지정)
  4. 컴퓨터마다 대시보드에서 자기 봇 토큰을 저장 → [휴대폰 연결] → 그 그룹에 아무 메시지나 보내기
  5. 이제 그룹에 주제를 보내면 컴퓨터마다 [블로그아이디] 가 붙은 답을 보내며 각자 글을 씁니다 (내용은 각자 새로 써서 서로 다릅니다)
