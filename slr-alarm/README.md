# SLR 장터 알림 (slr-alarm)

[SLR클럽 회원장터 > 팝니다](https://www.slrclub.com/bbs/zboard.php?id=used_market&category=1)에
**내 키워드가 제목에 들어간 새 글**이 올라오면 바로 알려 주고, 누르면 그 글이 열리는 링크를 주는 로컬 대시보드입니다.
인포러시(naver-information-)처럼 `npm start` 로 켜고 브라우저 화면의 버튼으로 씁니다.

## 설치와 실행

```bash
git clone -b claude/peaceful-einstein-lst1lc https://github.com/jettyy/phonenaver.git slr-alarm
cd slr-alarm
npm install
npm start          # → http://localhost:3100 (브라우저가 자동으로 열림)
```

다음부터는 폴더에서 이것만 하면 됩니다.

```bash
git pull
npm install        # 바뀐 게 없으면 금방 끝남
npm start
```

- Node.js 20 이상이 필요합니다 (`node -v`). 인포러시를 쓰고 있다면 이미 있습니다.
- 3100번 포트를 다른 프로그램이 쓰면 3101, 3102… 로 알아서 옮깁니다. 창에 찍힌 주소를 보세요. (직접 지정: `PORT=8080 npm start`)
- 브라우저를 자동으로 열지 않으려면 `NO_OPEN=1 npm start`.
- **창(터미널)을 닫으면 알림이 멈춥니다.** 켜 두고, 컴퓨터가 잠자기에 들어가지 않게 해 주세요.
- 코드를 고쳤으면 `npm run check` — SLR클럽에 접속하지 않고 목록 해석·키워드·새 글 판별·화면 API 를 점검합니다.

## 화면

| 칸 | 하는 일 |
|---|---|
| **1. 알림 받을 키워드** | 입력하고 [추가] (Enter 도 됨). 줄마다 스위치로 **켜기/끄기**(지우지 않고 잠시 쉬기), [삭제]. 키워드마다 알림 받은 건수 |
| **2. 알림 받은 글** | 찾은 글이 쌓입니다. 제목이나 [열기]를 누르면 SLR클럽 글이 새 탭으로 열림. 안 읽은 글은 초록 + NEW |
| **3. 지금 장터 목록** | 방금 읽어 온 첫 페이지. 키워드에 맞는 글은 초록색. [지금 확인] · [일시정지] |
| **4. 설정** | 확인 간격, 게시판 주소, 브라우저 알림 켜기, 알림 소리, 텔레그램, SLR클럽 로그인(보통 필요 없음) |

키워드·알림 받은 글·설정은 `data/slr-alarm.json` 에 저장되어 **껐다 켜도 그대로** 남습니다.

### 키워드 규칙

대소문자와 띄어쓰기는 무시합니다. `a7m5` 로 넣으면 `A7M5`, `A7 M5` 모두 찾습니다.

| 이렇게 넣으면 | 이런 제목을 찾음 |
|---|---|
| `소니 a7m5` | 두 단어가 **모두** 들어간 제목 |
| `a7m5\|a7v` | **둘 중 하나**라도 들어간 제목 |
| `라이카 -배터리` | '라이카'는 있고 '배터리'는 **없는** 제목 |

쉼표로 나누거나(`a7m5, 라이카 q2`) 여러 줄을 붙여넣으면 한 번에 여러 개가 들어갑니다.

## 알림이 오는 곳

1. **대시보드 화면** — 알림 받은 글 목록 + 탭 제목에 `(새 글 수)` + 딩동 소리
2. **맥/윈도우 알림** — 4번 칸 [브라우저 알림 켜기] 를 누르고 허용. 알림을 누르면 글이 바로 열림
3. **휴대폰 텔레그램 (선택)** — 제목·작성자·시간·링크와 [🔗 글 바로 보기] 버튼
   - 텔레그램에서 `@BotFather` → `/newbot` → 받은 토큰을 4번 칸에 넣고 [저장]
   - 휴대폰에서 내 봇에게 아무 메시지나 보낸 뒤 [채팅 자동 찾기] → [테스트 보내기]
   - 같은 폴더에 phonenaver(블로그 봇) 설정(`.env`)이 있으면 그 텔레그램 봇을 **자동으로 가져다 씁니다**

## 어떻게 도는가

- 60초(설정 가능, 최소 30초)마다 목록 첫 페이지를 읽고, **지난번 확인 이후 새로 올라온 글**만 키워드와 비교합니다.
  그사이 글이 많이 올라왔으면 3페이지까지 봅니다.
- 처음 켰을 때(또는 키워드를 새로 넣었을 때) 이미 올라와 있던 글로는 알림을 보내지 않습니다. 그런 글은 3번 칸에 초록색으로 보입니다.
- 같은 글은 한 번만 알립니다.
- 키워드가 하나도 켜져 있지 않거나 [일시정지] 중이면 사이트에 접속하지 않습니다.
- 확인이 5번 연속 실패하면 텔레그램으로 알리고, 다시 정상이 되면 또 알립니다.
- 목록이 로그인해야 보이는 경우에만 4번 칸에 SLR클럽 아이디/비밀번호를 넣으세요. 목록을 못 읽었을 때만 로그인합니다.
- 대시보드는 이 컴퓨터(`localhost`)에서만 열립니다.
