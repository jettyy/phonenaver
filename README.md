# phonenaver — 휴대폰으로 지시하면 네이버 블로그에 글을 써서 임시저장

**휴대폰(텔레그램)이나 PC 대시보드**에서 지시하면, 최신 정보·링크·사진을 분석해 글을 쓰고
문단 사이마다 사진과 카테고리까지 넣어 **네이버 블로그에 임시저장**합니다.
[인포러시(naver-information-)](https://github.com/jettyy/naver-information-) 와 같은 방식으로 씁니다.

```
git pull          # 최신 버전 받기
npm install       # 필요한 것 설치 (처음 한 번, 업데이트 후)
npm start         # 대시보드 열기 → http://localhost:3100
```

- **네이버**: 공식 API 없이 실제 브라우저로 씁니다. **대시보드에서 한 번만 직접 로그인하면 계속 유지됩니다.**
- **Claude**: API 키 없이 **내가 구독 중인 Claude 계정(Pro/Max)** 으로 동작합니다. (Claude Code CLI 사용)
  모델은 **sonnet 으로 고정**입니다 (사진 분석·최신 정보 조사·글 작성 모두).
- 발행은 하지 않습니다. 네이버 앱 → 글쓰기 → **임시저장 글**에서 확인한 뒤 직접 발행하세요.

```
휴대폰(텔레그램) ─┐
                  ├─▶ 작업 대기열 ─▶ ① 사진 분석 / 링크 읽기 / 최신 정보 웹 검색
PC 대시보드 ──────┘                  ② Claude(내 구독)가 글 작성 + 카테고리 선택 + 이미지 자리 지정
                                     ③ 계속 열려 있는 브라우저(로그인 유지)로 네이버 글쓰기 →
                                        제목·본문·문단 사이 사진·카테고리 → [저장] = 임시저장
                  ◀── 휴대폰으로 완료 알림 + 에디터 화면 캡처 / 대시보드 작업표에 기록 ──
```

## 할 수 있는 것

| 휴대폰 메시지 / 대시보드 2번 칸 | 동작 |
|---|---|
| `2026 청년도약계좌 조건 정리해줘` | 키워드/문장 → **최신 정보 웹 검색** 후 글 작성 → 임시저장 |
| `https://... 이거 분석해서 후기 글로 써줘` | 링크에 **들어가서 내용 분석** 후 글 작성 (네이버 블로그·카페 링크도 지원) |
| `https://youtu.be/... 이 영상 내용으로 글 써줘` | **유튜브 영상의 대사(자막)를 끝까지 읽고** 핵심을 분석해서 블로그 글로 새로 작성. `최신 정보도 찾아서` 를 붙이면 영상 내용을 최신 정보로 확인까지. 출처(유튜브) 언급 없이 씀 |
| `제주 한달살기 준비물 글 써줘. 이 링크 넣어줘 https://...` | 글을 쓰면서 그 **링크를 본문에 하이퍼링크로 삽입** |
| `이 기사 분석해줘 https://A`<br>`마지막에 이 링크 걸어줘 https://B` | 여러 줄이면 `넣어/삽입/걸어/첨부`가 적힌 줄의 링크만 삽입, 나머지는 분석용 |
| `그대로: 제목`<br>`본문...` | AI 없이 **내가 쓴 글 그대로** 임시저장 (본문 안 URL은 자동 링크) |
| 사진만 보내기 (설명 없어도 됨) | 사진 내용을 **분석해서 그 내용으로 글 작성**. 사진 자체는 **첨부하지 않음** |
| 사진 + `카페 후기로 1500자 써줘` | 사진 분석 + 지시 반영해서 작성 (첨부 안 함) |
| 사진 + `사진도 첨부해줘` | 꼭 사진을 글에 넣고 싶을 때만 이렇게 말하기 |
| 긴 글 통째로 붙여넣기 | 글 **전체**를 분석 → 항목마다 **최신 정보로 확인** → 틀리거나 오래된 내용은 고쳐서 **새로 작성** |
| `카테고리: 여행` 을 같이 쓰기 | 카테고리 직접 지정 (안 쓰면 내 블로그 카테고리 중 **알아서 골라서** 넣음) |
| `사진 없이` 를 같이 쓰기 | 이미지 없이 글만 |
| `/test ...` | 저장하지 않고 미리보기만 받기 (이미지도 함께 보여 줌) |
| `/categories` | 내 블로그 카테고리 목록 새로고침 |

### 글 모양: 문단 사이 빈 줄 + 문단 사이마다 사진
- 문단·소제목·표·사진 사이마다 **빈 줄 2개** (`PARAGRAPH_GAP`)
- 사진은 **도입부 뒤 1장 + 소제목 앞마다 1장** 씩 글 전체에 고르게 (`IMAGE_PER_SECTION`, 최대 `MAX_IMAGES`=8장)
- 사진 채우는 순서: 첫 장은 **제목 썸네일 카드** → **Pexels 무료 사진**(키가 있으면, 섹션 내용에 맞게 Claude 가 검색어를 정함) → 없으면 소제목 문구 **카드 이미지**
- 에디터의 [사진] 버튼으로 실제 업로드하므로 네이버 서버에 정상 저장됩니다
- 대시보드 4번 칸에서 모두 바꿀 수 있습니다

### 유튜브 링크
- 영상 제목·채널·설명과 **대사(자막) 전체**를 가져와 분석합니다. 자막은 한국어(사람) → 한국어(자동 생성) → 영어 → 그 밖의 언어 순서로 고릅니다
- 말로 한 내용이라 구어체·반복·자동 자막 오타를 정리해서 블로그 글 구성으로 **새로 씁니다** (자막 문장·순서를 그대로 따르지 않음)
- 유튜브·영상·채널 같은 **출처 언급 없이** 직접 정리한 정보글처럼 씁니다. 영상 속 사람의 개인 경험을 내 경험처럼 쓰지는 않습니다.
  그래도 본문에 '유튜브', '영상에서' 같은 말이 남으면 작업표·휴대폰에 경고를 띄웁니다
- 자막이 꺼져 있는 영상은 대사를 가져올 수 없어서 제목·설명만으로 쓰고, 작업표·휴대폰에 "유튜브 자막 없음" 경고를 띄웁니다
- `watch?v=`, `youtu.be/`, `shorts/`, `live/` 주소 모두 됩니다

### 휴대폰에서 보낸 메시지는 합쳐서 하나로
텔레그램은 긴 글을 붙여넣으면 **여러 메시지로 쪼개서** 보냅니다. 연달아 온 메시지(4초 안)는 **하나의 요청으로 합쳐** 글 한 편으로 씁니다.
앨범 사진, 사진+설명도 같이 합쳐집니다. (그래서 보내고 4초 정도 뒤에 작업이 시작됩니다)

말투·분량·대상은 메시지에 같이 쓰면 됩니다. (예: `1500자로`, `초보자용으로`, `리스트 위주로`)
링크만 주면 링크 내용만으로 쓰고, `최신`/`검색`/`찾아` 같은 말을 넣으면 웹 검색도 함께 합니다.

## 설치와 실행 (맥·윈도우 똑같이)

### 처음 한 번
1. **Node.js**(https://nodejs.org) 와 **Python 3.9 이상**(https://www.python.org/downloads/ — 윈도우는 "Add python.exe to PATH" 체크)을 설치합니다.
   맥은 파이썬이 기본으로 있어서 Node.js 만 설치하면 됩니다.
2. 터미널(맥) / 명령 프롬프트(윈도우)에서:
   ```
   git clone -b claude/eloquent-mccarthy-3mz2z7 https://github.com/jettyy/phonenaver.git
   cd phonenaver
   npm install
   ```
   `npm install` 이 알아서 합니다: 파이썬 패키지 · 글쓰기용 브라우저 · **Claude Code 설치와 구독 계정 로그인**(브라우저가 열리면 로그인).

### 실행
```
cd phonenaver
npm start
```
브라우저에 **대시보드(http://localhost:3100)** 가 자동으로 열립니다. 터미널 창은 켜 둔 채로 두세요 (닫으면 봇도 꺼집니다).
`start.command`(맥) / `start.bat`(윈도우) 더블클릭도 `npm start` 와 같습니다.

### 업데이트
```
git pull
npm install
npm start
```

### 대시보드 처음 설정 (한 번만)
| 칸 | 할 일 |
|---|---|
| **1. 네이버 로그인** | **[네이버 로그인 창 열기]** → 뜬 창에서 직접 로그인 ('로그인 상태 유지' 체크 추천). 블로그 아이디는 자동으로 채워집니다 |
| **3. 휴대폰 연결** | 텔레그램 `@BotFather` → `/newbot` 으로 받은 토큰을 넣고 **[토큰 저장]** → **[휴대폰 연결]** 을 누르고 휴대폰에서 봇에게 아무 메시지나 보내기 |
| **4. 설정** (선택) | Pexels 무료 사진 키, 이미지 수, 브라우저 창 보이기 등 |

그다음부터는 `npm start` 만 하면 봇도 자동으로 켜집니다.

### 대시보드에서 할 수 있는 것
- **2. 글쓰기 요청** — 휴대폰으로 보내는 것과 똑같이 입력하고 [글 쓰고 임시저장] / [미리보기만]. 사진 첨부 + "분석+첨부 / 분석만" 선택
- **⭐ 이 요청을 버튼으로 저장** — 자주 쓰는 요청을 버튼으로 남겨 두고, 누르기만 하면 다시 채워집니다 (계속 유지)
- **5. 작업 목록** — 휴대폰·PC 요청이 한 줄로 서서 차례대로 처리됩니다. 진행 상황, 제목, 카테고리, 이미지, 본문 미리보기, 에디터 화면 캡처, [다시] / [삭제]
- **진행 로그** — 지금 무엇을 하고 있는지 실시간으로
- 봇 켜기/끄기, 카테고리 불러오기, Claude 연결 확인·로그인

## 여러 컴퓨터(여러 블로그)에 한 번에 시키기

컴퓨터 3대에 각각 다른 네이버 아이디로 로그인해 두고, **한 번 보내면 3대가 같은 주제로 각자 글을 써서 각자 블로그에 임시저장**하게 할 수 있습니다.
(주제는 같아도 컴퓨터마다 따로 조사하고 새로 쓰기 때문에 글 내용은 서로 다릅니다)

텔레그램 봇 하나는 **한 컴퓨터에서만** 켤 수 있습니다. 같은 봇을 두 곳에서 켜면
`telegram.error.Conflict: terminated by other getUpdates request` 오류가 나고, 이 프로그램은 그 봇을 끄고 대시보드에 안내를 띄웁니다.
그래서 **컴퓨터마다 봇을 하나씩 만들고, 봇들을 한 그룹에 넣습니다.**

1. @BotFather 에서 컴퓨터 수만큼 봇 만들기 (예: 블로그A봇, 블로그B봇, 블로그C봇)
2. 각 봇마다 @BotFather → `/setprivacy` → 봇 선택 → **Disable** (그룹의 모든 메시지를 받게 함)
3. 텔레그램에서 **새 그룹**을 만들고 봇 3개를 모두 초대 (2번 전에 초대했다면 빼고 다시 초대하거나, 봇들을 그룹 관리자로 지정)
4. 컴퓨터마다 대시보드 3번 칸에서 **자기 봇 토큰** 저장 → **[휴대폰 연결]** → **그 그룹에** 아무 메시지나 보내기
5. 이제 그룹에 주제를 보내면 컴퓨터마다 `[블로그아이디] ✅ 임시저장 완료` 처럼 답하며 각자 씁니다

그룹에서 `/test 주제`, 사진, 긴 글 붙여넣기 모두 똑같이 됩니다. 한 대에만 시키고 싶으면 그 봇과의 1:1 대화에 보내면 됩니다
(1:1 대화도 쓰려면 [휴대폰 연결] 을 한 번 더 해서 1:1 대화도 등록하세요. 등록된 곳은 여러 개가 될 수 있습니다).

## 네이버 로그인이 유지되는 이유 (차단 방지)

예전 버전은 글을 쓸 때마다 브라우저를 새로 띄웠습니다. 네이버 로그인 쿠키 중 일부는 **브라우저를 닫으면 사라지는 쿠키**라서
매번 로그인이 풀렸고, 그때마다 아이디·비밀번호로 다시 로그인하다가 **반복 로그인으로 차단**될 수 있었습니다.
지금은 인포러시와 같은 방식입니다.

1. **로그인은 사람이 창에서 직접 한 번만.** 프로그램은 아이디·비밀번호를 입력하지도, 저장하지도 않습니다
2. **브라우저를 프로그램이 켜져 있는 동안 계속 열어 둡니다.** 글마다 탭만 열고 닫습니다
3. **로그인 쿠키를 `data/naver-cookies.json` 에 따로 보관**했다가, 프로그램을 다시 켰을 때 없으면 되살립니다
4. 로그인이 정말 풀렸으면 **자동으로 다시 로그인하지 않고** 글도 쓰지 않은 채 멈춥니다 (Claude 사용량도 안 씀).
   휴대폰과 대시보드에 "로그인 필요" 가 뜨면 [네이버 로그인 창 열기] 로 한 번 로그인하고 [다시] 를 누르세요

> 예전 버전에서 `.env` 에 넣었던 `NAVER_ID` / `NAVER_PW` 는 더 이상 쓰지 않습니다. 지워 두세요.

### 알아두면 좋은 것
- 사진 분석·검색·글 작성 모두 **Claude 구독 사용량**에서 차감되고, 한도에 걸리면 알려 줍니다.
- 봇은 PC 가 켜져 있고 `npm start` 창이 열려 있는 동안만 지시를 받습니다. 잠자기(절전)에 들어가지 않게 해 주세요.
- 명령어로 직접 쓰기: `.venv` 를 켜고 `python -m phonenaver write "주제" --dry`, `categories`, `check`, `login`

## 구조

| 파일 | 역할 |
|---|---|
| `phonenaver/command.py` | 메시지 해석 (링크 추출, 삽입용/분석용 구분, 검색 여부, `그대로:`·`/test`) |
| `phonenaver/fetcher.py` | 링크 본문 추출 (네이버 블로그 PC 주소 → 모바일 주소 변환, naver.me 단축주소) |
| `phonenaver/ai.py` | Claude(구독, `claude -p`): ⓪ 사진 분석 ① 웹 검색으로 최신 정보 조사 ② 제목·본문·태그·카테고리·이미지 계획 작성 |
| `phonenaver/images.py` | 이미지 준비 (Pexels / 카드 생성), 문단(소제목) 사이마다 사진 자리 정하기 |
| `phonenaver/html_utils.py` | 본문 HTML 정리(허용 태그만), 빠진 삽입 링크 보정 |
| `phonenaver/browser.py` | 네이버용 브라우저를 계속 열어 두고 로그인 유지 (직접 로그인 창, 쿠키 보관·복원, 블로그 아이디 찾기) |
| `phonenaver/naver.py` | Playwright: 제목 입력 → 서식 있는 본문 붙여넣기 → 사진 업로드 → 카테고리 선택 → **저장** |
| `phonenaver/pipeline.py` | 글 한 편의 전체 흐름 |
| `phonenaver/jobs.py` | 휴대폰·PC 요청을 한 줄로 세워 차례대로 처리, 작업 기록 |
| `phonenaver/bot.py` | 텔레그램 봇 (대시보드에서 켜고 끔) |
| `phonenaver/web.py`, `phonenaver/web/` | 대시보드 (인포러시와 같은 디자인) |
| `package.json`, `scripts/run.js`, `launcher.py` | `npm install` / `npm start` → 파이썬을 찾아 설치·실행 |

## 알아둘 점

- 네이버 공식 API 는 쓰지 않고 실제 브라우저로 로그인해서 에디터를 조작합니다. (카테고리 목록은 로그인된 브라우저로 내 블로그 화면이 쓰는 정보를 읽고, 안 되면 에디터의 발행 설정 창에서 읽습니다)
  네이버가 에디터 화면을 바꾸면 동작이 깨질 수 있으며, 이때는 `phonenaver/naver.py` 맨 위 `SELECTORS` 만 고치면 됩니다.
  실패하면 휴대폰과 대시보드 작업표에 **오류 당시 화면 캡처**가 남습니다.
- 카테고리는 [발행] 설정 창을 열어 고른 뒤 **발행하지 않고 닫습니다.** 태그는 본문 끝에 `#해시태그`로 붙습니다
  (`APPEND_HASHTAGS=false` 로 끌 수 있음).
- AI 가 쓴 글은 발행 전에 꼭 사실관계를 확인하세요. 짧은 시간에 많은 글을 자동으로 올리면 네이버 저품질/어뷰징 판정 위험이 있습니다.
- 다른 사람 글을 분석할 때는 그대로 베끼지 않고 재구성하도록 되어 있지만, 저작권은 사용자가 최종 확인해야 합니다.
